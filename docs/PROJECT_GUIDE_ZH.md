# 项目原理说明：碎纸文档自动重建

## 这个项目在研究什么？

把一页纸切成很多竖直纸条并打乱后，人可以借助文字、表格线和图片边缘把它拼回去。本项目让程序做同样的事情：输入的是**被打乱的纸条图像**，输出是它们可能的从左到右排列。

这类问题和碎纸证据整理、受损档案修复、历史文献数字化有关。不过本项目是课程原型：它处理等宽的规则竖直纸条，不等同于恢复真实物理碎纸。

## 程序如何工作？

1. 选择一页完整文档，再切成 8、10 或 12 条竖直纸条。
2. 把纸条随机打乱。此时算法只看到打乱后的像素。
3. 对任意两条纸条，程序都问一个局部问题：“A 放在 B 的左边像不像原本相邻？”
4. 有了所有纸条对的分数后，全局优化器找出一条总分最高的完整路径，也就是预测顺序。
5. 预测结束后，才把预测顺序和切条时保存的真实顺序比较，计算准确率并标出错误位置。

真实顺序不会参与第 3、4 步。因此页面上的红框和准确率是事后评测信息，不是算法的提示。

## 规则匹配和学习匹配有什么区别？

**规则匹配**由人工设计判断依据。例如两条纸条接缝两侧的颜色是否连续、文字笔画或表格线是否自然延续、边缘梯度是否相近。它会尝试有限范围的上下对齐，再把这些特征按固定权重合成一个分数。

**学习匹配**使用同一类局部信息，但不预先规定每个信息有多重要。项目用轻量的 Logistic Regression，从大量“确实相邻”和“并不相邻”的纸条对中学习特征权重。它还包含对齐带来的分数改善、偏移量和有效重叠比例等输入。

可以把两者理解为：规则匹配像老师事先写好打分标准；学习匹配像让模型从带答案的练习题里学习哪些线索更可靠。

## 训练数据从哪里来？

训练页由项目程序生成，包含报告、表格、图文混排和稀疏版式。程序还会模拟轻微模糊、亮度差、边缘缺失和上下错位。训练时，原始页面的左到右相邻关系可以作为标签；测试或实际演示时，模型不再读取这些标签。

演示图库中的公开页面只用于展示和测试，不进入训练。它们先是完整文档页，随后才被程序模拟切条，因此不能称作物理碎纸扫描数据。

## 为什么仅靠局部得分还不够？

一条纸条右边可能和多条纸条都“看起来还不错”：例如整页有重复段落、长表格线或大片空白。逐条贪心地选择最高分很容易冲突——两条纸条可能都想接在同一条后面。

项目使用 Held–Karp 动态规划，在“每条纸条只能使用一次”的约束下比较完整排列，寻找总兼容度最高的方案。这就是“局部兼容度 + 全局优化”的意义。

## 如何理解准确率？

- **相邻匹配正确率**：预测排列中，正确相邻的纸条对占全部相邻对的比例。10 条纸条有 9 个相邻关系。
- **完全恢复**：全部纸条的位置和顺序都正确才算成功。它比相邻匹配正确率严格得多。
- **运行耗时**：本次实际使用当前打乱输入进行预测所花的时间。

因此，一张页面即使相邻匹配达到 89%，也不一定是完全恢复；剩下一个错误接缝就会使整页完整恢复失败。

## 为什么规则方法有时更好？

学习方法不保证天然优于规则方法。若训练页和当前页面差异很大，或文字/表格线产生很多相似接缝，模型学到的权重可能不适合当前情况。规则方法中的一些强先验（如页面边界）也可能恰好有效。

正式实验中既有学习方法领先的情况，也有规则方法领先的情况。保留两者的并排结果和失败案例，正是为了避免只挑选好看的数字。

## 本项目最终得到了什么结论？

在一个未参与开发的最终确认集（24 个原始文档族、120 个观察案例）中，规则匹配的平均相邻恢复率为 80.73%，学习匹配为 78.32%。但把同一原始页面的五种观察先平均后再做重采样，二者差值的 95% 区间仍跨过 0；因此不能把“规则更好”写成普遍结论。

更可信的说法是：学习匹配在去掉页面边框和连续纹理时表现更好，说明它相对不依赖这些人工线索；规则匹配在上下错位和图文混排时更可靠。每种类型与条件的组合只有少量页面，页面会标明其证据不足。详情见 [`RESEARCH_SUMMARY_ZH.md`](RESEARCH_SUMMARY_ZH.md)。

## 当前不能解决什么？

- 真实扫描纸条的旋转、倾斜、阴影、纸张褶皱和不规则撕裂；
- 纸条重叠、缺片、宽度不等或任意形状碎片；
- 仅凭很少纹理的空白页面可靠判定方向；
- 将“完整公开页面模拟裁切”的结果当作真实物理碎纸恢复效果。

下一步最值得做的是收集带人工标签的小规模物理碎纸扫描数据，并在严格跨来源测试中验证更鲁棒的局部表示。
