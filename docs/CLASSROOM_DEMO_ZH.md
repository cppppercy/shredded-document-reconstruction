# 1～2 分钟课堂演示操作

启动：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

1. 打开“自动重建”，在“演示文档”中选择一张文字报告或表格页。
2. 选择 8 条纸条，点击“切成纸条”。说明此时纸条仍保持原顺序，程序尚未预测。
3. 点击“随机打乱”。指出上方数字只是当前输入位置，不是正确答案；可再点一次产生新的排列。
4. 点击“开始重建”。等待规则匹配与学习匹配对**同一组**打乱纸条完成预测。
5. 保持“并排比较”，展示两张恢复图、相邻匹配正确率、完整恢复与耗时。打开“标记错误纸条位置”说明红框只在预测后出现。
6. 若要展示局限，改选一张图文混排或表格页面后重复 2～5 步；不要承诺每次都会完全恢复。

备用：切到“实验分析”展示固定实验图和真实外部页面成功/失败案例。外部页面是完整页面的模拟裁切，并非物理碎纸扫描。
