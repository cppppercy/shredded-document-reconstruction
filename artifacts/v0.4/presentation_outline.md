# 《基于局部特征学习与全局优化的碎纸文档自动重建》5 分钟汇报草案

本草案只使用已保存的实际运行结果；“外部页面”均指完整公开页面经程序模拟竖直裁切，**不是**物理碎纸扫描。

## Slide 1｜问题、意义与边界（约 40 秒）

**页面内容**

- 目标：从打乱的规则竖直纸条恢复一页文档的左右顺序。
- 应用动机：司法证据整理、受损档案与历史资料数字化的辅助研究。
- 当前边界：规则直条、无旋转/重叠/缺片；不声称可恢复任意真实物理碎纸。

**讲稿**

“我们研究的不是把答案记下来，而是让程序只看被打乱纸条的图像内容，自动推断哪些纸条应当相邻。这个问题与受损档案和碎纸证据的数字化整理有关，但我们的实验原型只处理规则竖直纸条。真实物理碎纸常有旋转、撕裂和缺片，因此不能把本项目的结果外推成任意场景都可用。”

## Slide 2｜方法：局部兼容度 + 全局优化（约 70 秒）

**页面内容**

```text
完整文档 → 模拟裁切/打乱 → 为每一对纸条计算“左接右”的兼容度
                                  ↓
                   Held–Karp 动态规划找总兼容度最高的完整排列
```

- 传统 V0.2：接缝像素、梯度和轮廓等人工特征，尝试有限的非循环上下对齐。
- 学习 V0.3：用 Logistic Regression 学习这些局部特征的权重；额外输入“对齐收益、偏移量、有效重叠比例”。
- 真正预测时不读取正确顺序；正确顺序只用于训练标签和事后指标。

**讲稿**

“机器学习的角色不是直接输出整页答案。它先给每一个有向纸条对打分：A 放在 B 左边像不像真的相邻。然后全局动态规划综合所有局部打分，避免只按局部最优贪心拼接。V0.3 仍是轻量、可解释的逻辑回归：它学习特征权重，同时对有限上下错位寻找更合理的接缝。”

## Slide 3｜实验设计与机器学习贡献（约 70 秒）

**展示图**：`ablation-confirmation.png`

| 独立确认集：120 例 | 按文档平均相邻恢复率 |
| --- | ---: |
| 传统 V0.2 | 78.54% |
| 传统，去除端点辅助项 | 72.96% |
| 学习 V0.3，无干扰训练 | 77.39% |
| 学习 V0.3，无上下对齐特征/搜索 | 76.28% |
| 学习 V0.3，完整配置 | 77.78% |

**讲稿**

“为避免只在旧测试集上挑结果，我们新建了按原始文档身份隔离的训练、验证和确认集。完整学习模型相对无干扰训练提高 0.39 个百分点，相对无对齐提高 1.50 个百分点，说明这两项都有贡献，但改善很小。更重要的是，它在这批全新文档族上仍略低于传统 V0.2 的 78.54%。所以我们的结论不是‘学习一定更好’，而是数据增强和对齐能提高学习模型的鲁棒性，但当前特征模型仍不稳定。”

## Slide 4｜外部公开页面：成功与失败都展示（约 65 秒）

**展示图**：

- 成功：`success-v04-usgs-landstat-economic-valuation-10-external_page_simulated_cut-usgs-landstat-economic-valuation-9.png`
- 失败：`failure-v04-gpo-annual-report-2023-10-external_page_simulated_cut-gpo-annual-report-2023-4.png`

**页面内容**

- 新增 3 个来源、共 6 页：USGS、NIST、GPO；均只用于测试。
- 学习 V0.3：82.76% 相邻恢复率，1/6 完整恢复；传统：77.22%，0/6 完整恢复。
- V0.3 旧外部集曾为 8/10 完整恢复，但它只有两份 OSTP 报告，不能代表跨版式泛化。

**讲稿**

“这页最能说明为什么要继续做外部验证。我们加入三个此前没见过的公开来源，结果学习模型只完整恢复了六页中的一页。左边是成功页，右边是保留的失败页。它们仍然只是把真实完整页面模拟切条，不是物理碎纸扫描；但已经暴露了不同版式、表格和大面积图形会让局部边缘更模糊。”

## Slide 5｜现场演示、结论与下一步（约 55 秒）

**页面内容**

1. Streamlit 选“成功示例”：原图 → 打乱条 → 传统/学习恢复 → 指标。
2. 切换“失败示例”：红框仅在预测后显示错误，解释边缘缺失/重复结构的歧义。
3. 结论：全流程可运行、结果可复现、机器学习增益受数据分布制约。
4. 下一步：收集有人工标签的物理碎纸扫描；针对边缘缺失设计更鲁棒的局部表示；扩大跨来源盲测。

**讲稿**

“最后我演示同一页面的打乱和两种真实重建结果。红框是评测后才显示的，不会反馈给算法。项目已经具备从生成、训练、全局优化到可视化的端到端流程，也诚实保存了失败案例。下一步最需要的不是堆叠更大模型，而是更接近真实碎纸的数据和更严格的跨来源盲测。”

## 现场操作清单与备用材料

1. 启动：`./.venv/Scripts/python.exe -m streamlit run app.py`。
2. 先运行“成功示例”，再运行“失败示例”；不要临时修改种子或顺序。
3. 若浏览器/网络不可用，按 Slide 4 使用上述两张真实运行图，按 Slide 3 使用 `ablation-confirmation.png`。
4. 可上传 PNG/JPG：程序先切条并打乱，真实顺序只用于最终指标；上传的完整原图并不作为预测捷径。
